# AIWF v6.29.0

Released 2026-10-19.

- Initialization and project updates reuse globally installed skills instead of
  creating duplicate project skill trees.
- Blocking AIWF gates are off by default. Skipped checks report SKIPPED and do
  not manufacture approval or successful verification evidence.
- Every new Blueprint level uses CONTRACT. Spikes are optional.
- Shared-runtime commands retain the calling project's identity and use working
  Python interpreters on Windows. Disabled Git hooks exit immediately.

To retain historical enforcement, explicitly set `AIWF_GATE_MODE=enforce`.
Existing project-owned skills, state and frozen artifacts remain intact.
Actual compilation, lint, test and command failures remain visible.
